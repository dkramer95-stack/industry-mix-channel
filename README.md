# The Industry Mix Channel

**AI exposure and U.S. state labour markets, 2016–2025**

A shift-share design on 51 states: did economies whose 2019 industry composition was more exposed to language-model AI diverge after 2022? With pre-trends, a placebo, and permutation inference.

[Paper (PDF)](paper/industry-mix-channel.pdf) · [Markdown](paper/industry-mix-channel.md) · [Every number](analysis/stats.json)

## The result, stated plainly

| | |
|---|---|
| Exposure | State exposure = 2019 industry shares × AIIE industry scores; DC highest (+3.3), Wyoming lowest (−2.3) |
| Pre-trends (2016–18) | flat: +0.11%, +0.20%, +0.10% per SD, t ≤ 1.0 |
| Post-2022 event study | negative and growing: −0.66% (2022) to −1.18% (2025) per SD |
| Placebo (fake 2018 treatment) | −0.00% to −0.11%, nothing |
| Permutation inference | actual coefficient at the **27th percentile** of 1,000 shuffles, **p = 0.27** |

**The finding is a null.** The point estimate points the way the displacement hypothesis predicts, and the design cannot distinguish it from noise. The paper explains why: state log employment is nearly a fixed effect, so fixed effects absorb 99.95% of the variance; the exposure measure is capability, not adoption; and state aggregation dilutes the treatment.

## What it is for

It is a reusable template — composition data, external exposure scores, an event study, a placebo, permutation inference — and a caution about the level at which this question can be answered. The companion papers argue the variation is inside firms and occupations, not between states.

## Reproduce

```bash
python3 pipeline/fetch_qcew.py
python3 pipeline/fetch_bls.py
python3 analysis/analyze.py      # needs pandas + numpy
```

Spot checks: `event_study.coef` for 2025 is −0.0118; `permutation.p_two_sided` is 0.268.
